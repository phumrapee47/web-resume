Clinical Background & Objective

Early detection of Alzheimer’s Disease and Mild Cognitive Impairment (MCI) is critical for administering preventative care and cognitive therapy. This project builds a clinical decision support system utilizing supervised machine learning to classify patients into diagnostic stages based on standardized neuro-psychological assessments and medical metrics.

🧠

Cognitive Indicator Modeling

Evaluates Mini-Mental State Examination (MMSE), Clinical Dementia Rating (CDR), Functional Activities Questionnaire (FAQ), and Normalized Brain Volume.

📊

Feature Importance & Interpretability

Identifies key clinical biomarkers contributing to stage progression, assisting healthcare practitioners with data-backed diagnoses.

⚙️

Robust Data Preprocessing

Employs SMOTE class balancing, robust outlier handling, and Stratified K-Fold Cross Validation to prevent medical data bias.

🌐

Interactive Web Demo Interface

Web-based diagnostic calculator allowing practitioners to input test scores and view real-time disease probability distributions.

Machine Learning Pipeline

Pipeline Architecture

Supervised Pipeline
1
Data Ingestion & Clinical Cleaning

Ingests patient clinical records, handles missing biomarker measurements with iterative imputation, and normalizes numeric ranges.

2
Feature Selection & Correlation Analysis

Extracts high-signal predictors and eliminates collinear features using Pearson correlation and mutual information scores.

3
Ensemble Model Training & Hyperparameter Tuning

Trains and compares Random Forest, XGBoost, and Support Vector Machine classifiers with GridSearchCV optimization.

4
Cloud Deployment & Inference Endpoint

Deploys serialized model pipeline to Render Cloud with an interactive web UI for real-time risk assessment scoring.
