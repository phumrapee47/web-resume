End-to-End System Architecture

This restaurant ordering ecosystem replaces traditional paper menus and fragmented order taking with an automated, synchronized real-time workflow across three micro-services:

Real-Time Communication Pipeline

Full-Duplex Data Sync
1
Customer Ordering (LINE LIFF Web App)

Customer opens the app inside LINE via LIFF, browses categories, adds items to cart with special instructions, and places an order with 1-click verification.

2
Central Database & Event Trigger (Supabase PostgreSQL)

Orders are committed to Supabase with real-time change events immediately broadcasting status updates to all connected instances.

3
Kitchen Order Board (Admin Dashboard)

Kitchen staff view incoming tickets in real-time, accept orders, update preparation stages (Cooking → Ready → Completed), and manage restaurant inventory.

4
Automated Customer Notifications (LINE Messaging Bot)

The Node.js LINE bot pushes rich Flex Message receipts and real-time status alerts (Order Confirmed, Food Ready for Pickup) directly into the customer's LINE chat.
