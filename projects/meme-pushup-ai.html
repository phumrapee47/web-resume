Project Overview & Motivation

Most webcam-based fitness demos either require a native mobile app or stream video to a server for pose estimation, adding latency and privacy concerns. Meme Push-Up solves this by converting a YOLOv8n model into a TensorFlow.js GraphModel that runs the entire detection pipeline in the browser — rep counting works fully client-side with no video ever leaving the device.

📷

Client-Side YOLOv8 Detection

Loads a converted YOLOv8n GraphModel via TensorFlow.js and runs 640×640 inference on live webcam frames every animation frame, decoding boxes with a custom confidence/NMS post-processor.

📏

Depth-Based Rep Counter

Tracks the person bounding box's vertical position against a virtual "depth target" line; a full UP → DOWN → UP cycle registers as one completed rep, with a threshold to reject detection noise.

🔥

Combo & Streak Engine

Reps completed within a 3-second window chain into a combo multiplier. Max combo is tracked per session and drives escalating visual feedback like a rainbow border effect.

💾

Session Persistence

Completed sessions (rep count + max combo) are saved to Supabase Postgres through Next.js API routes, with a dedicated history page for reviewing and deleting past sessions.

Gamification & Feedback Layer

🎉

Meme Reward Overlay

Every 5th completed rep triggers a randomly-positioned meme GIF pop-up with a Framer Motion spring animation, auto-dismissing after 2.5 seconds for positive reinforcement.

📈

Stage Progression

Session elapsed time is bucketed into four stages (0–15s, 15–30s, 30–60s, 60s+), each driving a distinct on-screen stage overlay to keep the workout feeling alive.

🛠️

Debug Visualization Mode

A toggleable overlay renders live bounding boxes and the depth target line, making it easy to tune detection thresholds directly against the camera feed.

System Architecture & Data Flow

Client-Side Detection Pipeline

Zero Server-Side Video
1
Camera Capture

A CameraFeed component requests webcam access via getUserMedia and streams frames into a hidden video element for inference.

2
Client-Side Inference

TensorFlow.js loads the YOLOv8n GraphModel once on mount; each animation frame is resized to 640×640, normalized, and run through executeAsync entirely in WebGL.

3
Box Decoding & Person Tracking

Raw YOLO output is decoded and filtered to class 0 (person) above a confidence/IoU threshold, then rescaled and compared against a virtual bottom-center depth block.

4
Rep State Machine

The usePushUpCounter hook tracks UP/DOWN transitions, increments the rep count on each completed cycle, computes combo windows, and derives the session stage from elapsed time.

5
Persistence & History

Completed sessions are saved through /api/sessions (Next.js Route Handlers) to Supabase Postgres, with GET/POST/DELETE/PUT endpoints backing a dedicated history view.
